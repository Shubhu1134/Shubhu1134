# Achievement Sprint System

Use this system every week to build visible GitHub momentum fast.

## Weekly Targets
- 5 merged pull requests (own + external repos)
- 3 closed issues linked to PRs
- 2 meaningful code reviews/comments
- 1 discussion answer
- 1 VPS/DevOps improvement with docs

## Daily Cadence (60-90 min)
1. Pick one small issue.
2. Create branch and implement.
3. Open PR with checklist.
4. Merge and close issue.
5. Log outcome in weekly sprint issue.

## High-Leverage Repo Types
- Active public repos where you can submit small fixes quickly
- Your own repos with clear issue/PR workflow
- DevOps repos with CI/CD, Docker, deployment scripts

## Minimum Output per Week
- One merged `feat`
- One merged `fix`
- One merged `docs`
- One merged `chore` or `ci`
- One external contribution PR

## Notes
- Achievement badges are event-driven and can take time to appear.
- Keep activity consistent; consistency wins over one large dump.
