# Security Policy

## Supported Scope

This is a public profile and workflow-control repository. Security-sensitive work here usually means protecting repository automation, avoiding leaked credentials, and keeping public links safe.

## Reporting

If you notice a security issue, please email `shubhu1134@gmail.com` with:

- A short description of the issue
- The affected file, workflow, or link
- Reproduction steps, if applicable
- Suggested fix, if you already have one

Please do not open public issues for secrets, credentials, tokens, or private infrastructure details.

## Repository Safety Rules

- Never commit secrets, tokens, private keys, `.env` files, or production credentials
- Keep workflow permissions as narrow as possible
- Prefer pull requests for automation changes
- Review generated links before merging profile README updates
