## Work That Produces the Best Signal
- Small public PRs that merge the same day
- Every change starts as an issue and ends as a merged PR
- One `docs`, one `fix`, and one `feat` or `chore` every week
- One external contribution PR every week
- One useful review/comment block every week
- One discussion answer every week

## Work That Slows You Down
- Direct pushes to `main`
- Huge branches for tiny changes
- Starting new repos instead of improving active public ones
- Spending multiple days on one invisible cleanup
- Opening PRs without linking an issue
