# Public Repo Acceleration Plan

Goal: maximize visible progress in short time with PR-based contributions.

## Priority Repos (Fast Wins First)
1. `Devops-Foundations`
2. `ci-cd-demo`
3. `docker-deploye-architecture`
4. `Advance-java-code-`
5. `WebDevelopment`
6. `Team-Practice-Java-Projects`

## 14-Day Execution Split

### Week 1
- `Devops-Foundations`: add CI workflow, improve docs, merge 2 PRs
- `ci-cd-demo`: fix pipeline edge cases, add status badges, merge 2 PRs
- `Advance-java-code-`: organize modules and examples, merge 1 PR

### Week 2
- `docker-deploye-architecture`: add production checklist and deployment scripts, merge 2 PRs
- `WebDevelopment`: ship one feature and one bugfix via PRs, merge 2 PRs
- `Team-Practice-Java-Projects`: add setup + contribution docs, merge 1 PR

## Non-Negotiable Rules
- Every change starts with an issue
- Every issue ends with a merged PR
- Keep PR scope small and shippable
- Log weekly output in sprint issues
